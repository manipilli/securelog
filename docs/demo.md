# Demonstration Flow

1. Register and sign in as an organization administrator.
2. Create an API client and ingest a sample log.
3. View the registered hash and confirmed blockchain transaction.
4. Verify the record and observe `VERIFIED`.
5. Change the source record and verify again to observe `TAMPERED`.
6. Review the alert, audit trail, report, and QR verification reference.

Demo credentials and sample records should be seeded only by an explicit development script.
